# Madrasah Darus Sunnah Poster Maker

মাদ্রাসার নাম, ঠিকানা, ব্যাচ, কোর্স ও শিক্ষাবর্ষ স্থায়ীভাবে নির্ধারিত। ফরমে শুধু ছাত্রের ব্যক্তিগত তথ্য ও ছবি দিতে হবে।

## GitHub Pages-এ আপডেট
1. Repository `abdulahad310/madrasa-poster-maker` খুলুন।
2. পুরোনো `index.html` ফাইলটি নতুন `index.html` দিয়ে replace করুন।
3. Commit changes দিন।
4. GitHub Pages কয়েক মিনিটের মধ্যে নতুন সংস্করণ প্রকাশ করবে।

ছাত্রের তথ্য ও ছবি ব্রাউজারেই প্রসেস হয়।
